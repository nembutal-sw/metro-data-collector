# 막차 경로 계산

## 서비스일 시각

자정 이후 운행을 같은 영업일에 유지하기 위해 시각을 0 이상의 정수 초로 저장합니다.
달력 날짜로 변환할 때만 서비스일 자정에 초를 더합니다.

## 역방향 CSA

도착 마감 요청은 목적지에서 출발지 방향으로 계산합니다.

1. 도착 마감에서 하차 후 도보와 안전 여유를 차감
2. 연결편을 출발시각 역순으로 검사
3. 도착역의 최신 허용시각보다 늦지 않은 연결만 완화
4. 환승 보행 연결을 역방향으로 완화
5. 출발역 접근 도보시간을 차감
6. 열차·환승 leg와 데이터 버전을 응답

정적 배열은 시간표 버전·서비스일별로 캐시합니다. 운행 중단, 무정차, 열차 취소는
활성 서비스 알림을 오버레이하여 연결을 제외합니다.

## 품질 시나리오

- 서울 2호선 단일 노선
- 서울 노선 간 및 코레일·인천 환승
- 자정 이후 도착과 공휴일
- 중간 종착·급행 통과
- 최소 환승시간 부족으로 마지막 연결 실패
- 출발·도착 도보와 추가 안전 여유
