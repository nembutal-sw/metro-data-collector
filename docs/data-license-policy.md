# 데이터 이용조건 정책

## 기본 경계

공식 기관이 익명 사용자에게 공개하고 명시적 금지 조건이 없는 데이터는 수집기를
기본 활성화합니다. 이용조건이 명시되지 않았다는 사실과 확인일을 DB에 기록합니다.

다음은 비활성화합니다.

- robots 규칙의 명시적 차단
- 약관의 자동 수집·저장·변형 명시적 금지
- 로그인·인증정보 공유·CAPTCHA·WAF 우회가 필요한 접근
- 화면에 공개되지 않은 비공개 API
- 출처를 확인할 수 없는 제3자 복제본

## 저장

- 허용: 원문 파일, 응답 헤더, 체크섬, 출처, 정규화 결과 보관
- 원문 저장 제한: 원문은 폐기하고 체크섬·헤더·출처와 허용된 정규화 데이터만 보관
- 변형 제한: 변형된 운영 데이터 활성화를 중단하고 원천 제공 요청

라이선스는 법률 자문을 대체하지 않으며, 운영·상업 배포 전에는 사용 조직의 최종
검토가 필요합니다.
