01

QUICK START

첫 번째 경로 요청

ODsay v1.8 도시 내 길찾기와 같은 result.path[].info/subPath[] 구조가 필요하면 아래 엔드포인트를 사용합니다. 출발역과 도착역은 부분 검색어가 아닌 확정된 역명이어야 합니다.

GET/odsay/v1/api/searchPubTransPathT
cURL
curl --get 'http://localhost:8080/odsay/v1/api/searchPubTransPathT' \
  -H 'X-API-Key: <발급받은_API_키>' \
  --data-urlencode 'origin=강남역' \
  --data-urlencode 'destination=서울역' \
  --data-urlencode 'departure_at=2026-08-23T09:00:00+09:00' \
  --data-urlencode 'walking_mode=standard'
역명 형식

강남과 강남역은 모두 허용합니다. 강 같은 부분 이름이나 강남역 2호선처럼 노선이 붙은 값은 허용하지 않습니다.

서울 시간대

시간대가 없는 값은 Asia/Seoul로 처리합니다. 가능하면 +09:00을 포함하세요.

02

ACCESS

인증과 호출 정책

경로 계산 APIX-API-Key

ODsay 호환 경로와 네이티브 소요시간 API는 발급된 소비자 키가 필요합니다.

관리 APIX-Admin-API-Key

동기화 실행 요청에만 서버 관리 키가 필요합니다.

외부 공공데이터 키서버 내부 전용

수집용 키는 소비자 요청에 전달하지 않으며 응답에도 노출하지 않습니다.

읽기 전용 조회인증 불필요

역·노선·수집원·운영 상태 조회는 문서와 운영 화면을 위해 공개합니다.

키 전달 방법: X-API-Key 요청 헤더를 권장합니다. ODsay 방식이 필요한 클라이언트는 ?apiKey=발급키 쿼리도 사용할 수 있지만 URL과 로그에 키가 남을 수 있습니다.

경로 요청 가능강남 강남역 검색만 가능강 남 권장검색 결과의 name_ko 그대로 사용

04

NEARBY STATIONS

위도·경도로 가까운 역 찾기

WGS84 좌표와 검색 반경을 전달하면 직선거리가 가까운 순서로 수도권 도시철도역을 반환합니다. ODsay 호환 응답과 거리까지 포함하는 네이티브 응답을 각각 제공합니다.

ODsay pointSearch 호환 요청

GET/odsay/v1/api/pointSearch
cURL · 강남역 주변 1km
curl --get 'http://localhost:8080/odsay/v1/api/pointSearch' \
  -H 'X-API-Key: <발급받은_API_키>' \
  --data-urlencode 'x=127.0276' \
  --data-urlencode 'y=37.4979' \
  --data-urlencode 'radius=1000' \
  --data-urlencode 'stationClass=2'
이름형식필수기본값설명
xdoubleY—경도(longitude). 서울권에서는 보통 126~128 범위입니다.
ydoubleY—위도(latitude). 서울권에서는 보통 37대입니다.
radiusintegerN250미터 단위 반경. 1~20,000.
stationClassstringN2현재 2(지하철역)만 지원합니다.
langintegerN0현재 국문(0)만 지원합니다.
outputstringNjsonJSON만 지원합니다.
apiKeystring조건부—X-API-Key 헤더를 사용할 수 없을 때 쿼리로 전달합니다.

좌표 순서 주의: x=경도, y=위도입니다. 두 값을 바꾸면 검색 결과가 없거나 전혀 다른 지역을 조회하게 됩니다.

05

PRIMARY ENDPOINT

ODsay v1.8 호환 경로 조회

GET과 POST를 지원합니다. 두 방식 모두 파라미터는 쿼리 문자열로 전달합니다. 현재는 버스가 없는 도시철도 경로 한 건을 반환하며, 계산 기준은 요청 시각 이후 가장 빨리 도착하는 경로입니다.

역명 입력 규칙

입력 예시사용 가능처리 방식
강남, 강남역가능마지막 역은 선택 사항이며 두 값은 같은 역으로 처리합니다.
서울, 서울역가능DB의 확정 역명과 일치하므로 모두 허용합니다.
어룡(용현산업단지)가능괄호가 포함된 공식 역명은 검색 결과의 전체 이름을 전달합니다.
강, 남불가역 검색에는 사용할 수 있지만 경로 요청은 정확히 한 역을 지정해야 합니다.
강남역 2호선, 222불가노선명과 역 코드는 붙이지 않습니다. 역명만 전달합니다.

요청 파라미터

이름형식필수기본값설명
originstringY—확정된 출발역명. 앞뒤·중간 공백은 제거되며 마지막 역은 선택 사항입니다.
destinationstringY—확정된 도착역명. 부분 이름, 노선명, 역 코드는 사용할 수 없습니다.

apiKeystring조건부—X-API-Key 헤더를 쓰지 못할 때만 사용하는 소비자 키입니다.
영업일 경계

자정부터 02:59:59까지는 전날 영업일로 계산하며 내부 시각은 24시 이후 값으로 이어집니다.

탐색 범위

요청 출발시각 이후 6시간 안에 출발하는 활성 열차를 대상으로 경로를 찾습니다.

분 단위 반올림

ODsay 호환 응답의 시간 필드는 초 단위 계산 결과를 올림한 정수 분입니다.

URL 직접 호출

브라우저 / HTTP GET
http://localhost:8080/odsay/v1/api/searchPubTransPathT?apiKey=<발급키>&origin=강남&destination=서울역&departure_at=2026-08-23T09:00:00%2B09:00

URL 인코딩: 쿼리 문자열에 시간대의 +를 직접 넣으면 공백으로 해석될 수 있으므로 %2B09:00으로 인코딩하거나 URL 인코더를 사용하세요.

JavaScript 호출

JavaScript
const params = new URLSearchParams({
  origin: '강남역',
  destination: '서울역',
  departure_at: '2026-08-23T09:00:00+09:00',
  walking_mode: 'standard',
});

const response = await fetch(
  `/odsay/v1/api/searchPubTransPathT?${params}`,
  { headers: { 'X-API-Key': '<발급받은_API_키>' } },
);
const payload = await response.json();

if (!response.ok) throw new Error(payload.error?.message ?? '경로 조회 실패');
console.log(payload.result.path[0].info.totalTime);

Python 호출

Python · requests

response = requests.get(

response.raise_for_status()
print(response.json()["result"]["path"][0]["info"])

이동 구간 subPath[]

1지하철

노선, 방향, 승하차역, 정차역 목록과 구간 소요시간을 포함합니다.

2버스

ODsay 규격에 존재하지만 현재 플랫폼은 반환하지 않습니다.

3도보

출입 및 환승 보행 구간입니다. 환승 여유시간은 구간 시간에 포함됩니다.

필드적용 구간설명
trafficType전체1 지하철, 2 버스, 3 도보.
distance전체미터 단위 거리. 좌표 미확보 시 열차 구간은 0일 수 있습니다.
sectionTime전체해당 구간 소요시간(분).
stationCount지하철승차역 다음부터 하차역까지 이동하는 역 구간 수.
lane[]지하철노선명, ODsay 호환 노선 타입, 도시코드.
intervalTime지하철해당 열차 탑승 전 실제 대기시간(분).
startName/endName지하철승차역과 하차역 이름.
startX/startY/endX/endY지하철경도·위도. 데이터 미확보 시 null.
way/wayCode지하철행선지 또는 운행 방향과 상·하행 코드.
door지하철빠른 환승 위치. 미확보 상태는 -2--2.
startID/endID지하철플랫폼이 생성한 로컬 정수 역 식별자.
passStopList.stations[]지하철순번, 로컬 역 ID, 역명과 좌표를 포함하는 전체 정차역 목록.

시간 계산: 총 소요시간 = 최초 열차 대기 + 열차 이동 + 환승 보행 + 환승 여유 + 환승 열차 대기입니다. 다음 열차가 환승 준비 완료 시각보다 빠르면 탑승 가능한 그다음 열차를 선택합니다.

07

COMPATIBILITY

ODsay 호환 범위

필드 배치와 지하철 노선 타입은 ODsay v1.8 도시 내 응답을 따르지만, 이 서비스가 ODsay의 데이터나 고유 식별자를 재배포하는 것은 아닙니다.

stationID

정수 형태의 플랫폼 로컬 식별자입니다. ODsay 역 ID와 교환해 사용할 수 없습니다.

subwayCode

ODsay 공식 노선 타입과 같은 코드값을 사용합니다. 미등록 신규 노선은 0입니다.

좌표와 거리

국가철도공단 공식 역 좌표를 사용합니다. 공급 원본의 비정상 좌표 또는 미매칭 역은 좌표·직선거리가 null일 수 있습니다.

mapObj / door

ODsay 지도 보간점은 제공하지 않습니다. 빠른 환승 객차 미확보 시 -2--2입니다.

경로 개수

현재는 요청 시각 기준 가장 빠른 도착 경로 한 건만 제공합니다.

실시간성

활성 정적 시간표 기준입니다. 당일 지연·운휴가 반영되지 않을 수 있습니다.
